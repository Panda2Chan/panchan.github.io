# 简历项目亮点文案调整设计

## 目标

将项目经历卡片底部面向简历作者的 AI 使用建议，统一改为面向招聘方的项目亮点总结。每个项目保留一句话，说明项目解决的问题、形成的能力或交付结果。

## 范围

- 将 `ResumeProject.aiRelevance` 重命名为 `projectHighlight`，类型由可选字符串数组调整为可选字符串。
- 为全部 5 个项目编写一句话项目亮点，避免“适合”“可使用”等建议语气。
- 网页项目卡片继续在现有灰底强调块中展示该字段。
- Markdown 简历将栏目名从“AI 相关”改为“项目亮点”。
- 同步 `docs/resume-data-structure.md` 中的字段定义和示例数据。
- 不调整独立的“AI 工程能力”模块及其证据文案。

## 文案原则

- `summary` 说明项目是什么；`projectHighlight` 说明项目解决了什么或形成了什么结果。
- 使用项目主语或省略主语的客观陈述，不评价简历作者，也不向作者提出建议。
- 每个项目只保留一个完整句子，不虚构缺少依据的量化数据。

## 数据流

```text
resume.ts 项目数据
        │
        ├── page.tsx 项目卡片强调块
        └── buildResumeMarkdown.ts “项目亮点”栏目
```

## 验收标准

- 项目数据、页面组件、Markdown 构建逻辑和结构文档中不再出现 `aiRelevance`。
- 5 个项目强调块均为一句话项目总结，不再出现“适合”“可使用 AI”等建议口吻。
- TypeScript、ESLint 和生产构建通过。
- 不修改与简历项目亮点无关的文件。
